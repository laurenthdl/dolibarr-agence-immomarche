# Immobilier - Marche

Module d'etude de marche immobilier (prix/m2) pour la Cote d'Ivoire.

## Numero de module
`700007`

## Dependances
- immocore (700000)

## Tables PostgreSQL
- `llx_immo_vente_comp` : Ventes comparables
- `llx_immo_location_comp` : Locations comparables

## Fonctionnalites
- Indexation manuelle des transactions reelles
- Calcul prix/m2 par quartier et type de bien
- Base de donnees des comparables pour estimation immobiliere
